# WaVe

![Licence: MIT](https://img.shields.io/badge/Licence-MIT-yellow?style=flat&labelColor=555) [![Open WaVe](https://img.shields.io/badge/Open-WaVe-orange?style=flat&labelColor=555)](https://imbeyondidentity.github.io/Wave/)

[English version](README.md)

Компилятор промптов для видеомодели
Wan версий 2.5, 2.7 и 3.0. Опиши
ролик обычными словами и получи
структурированный промпт, негативный
промпт и самопроверку. Работает в
браузере: без сервера и без ключа.

## Что умеет

- Расшифровывает бриф: тип сцены,
  свет, движения камеры, речь.
- Режет его на тайминги под выбранную
  модель.
- Пишет промпт в форме, которую
  каждая модель читает лучше всего.
- Собирает отдельный негативный
  промпт (до 500 символов).
- Проверяет результат и ставит оценку.
- Вкладка LLM: готовый мета-промпт
  для Claude или ChatGPT.
- История и ссылка с настройками.
- Интерфейс RU/EN.

## Модели

| | 2.5 | 2.7 | 3.0 |
|---|---|---|---|
| Длина | 5 или 10 с | 2-15 с | 2-30 с |
| Разрешение | 480-1080p | 720-1080p | 480-1080p |
| Шоты | один | мульти-шот | мульти-шот |
| Референсы | первый кадр | 5 + кадры | 20, доки |

Данные Wan 3.0, которые официально не
опубликованы (форматы, лимит промпта,
звук), помечены * во вкладке «Модели».

## Запуск

Открой index.html в любом браузере
или используй GitHub Pages:

```
Settings > Pages
Source: main, / (root)
```

Без сборки и без зависимостей.
